# Карточка модели Tiny-RU 2.1r3

## Назначение

Эксперимент с компактным символьным Transformer и офлайн-инференсом в DOS
и Windows. Модель рассчитана на короткие вопросы и короткие ответы по
небольшому набору фактов. Практическое применение — обучение, исследование
квантования и ограничений малых моделей, демонстрация работы на старой платформе.

## Архитектура и артефакты

4 слоя, D=96, 4 головы, FFN=256, 366 528 параметров; связанные входные/выходные
эмбеддинги. Контекст — 128 токенов, словарь — 97 токенов. Регистр приводится
к нижнему, буква «ё» сохраняется. Неподдерживаемые символы заменяются на `?`.

`training/release.pt` — чекпоинт PyTorch с весами и состоянием обучения.
`dos/TINY.BIN` и `windows/TINY.BIN` — одинаковые TNY2-веса по 381 808 байт.
Матрицы представлены int8 с масштабами float32 на строку; gains остаются float32.
C-runtime использует int8 KV-cache. SHA-256 BIN:

```text
222913b9b6f44642211c694ed188f988bfa7f106198889c55932b06abb808b55
```

## Обучение и данные

Русское обучение начиналось со случайных весов. Английский обученный чекпоинт
исходного проекта не использовался. После исходного этапа v2 и дообучения r2
выполнено 9500 дополнительных шагов для r3: 3000 + 5000 + 1000 + 500.
Seed — 42, два потока CPU. 80% выборок r3 посвящены новой области, остальные
повторяют прежние темы. Потери усредняются по примерам, чтобы короткие числовые
ответы не теряли вес по сравнению с длинными.

Набор России содержит 1000 связей «объект — свойство». Полный финальный train
с вариантами вопросов и повторением прежних тем содержит 37 581 строку.
Сведения относятся к срезу на 24 ноября 2026 года. Их источники указаны у записей.
Исторические данные Российской империи и СССР входят как связанная тематика.
Независимая проверка каждой импортированной связи не выполнялась.

Финальный набор — [data/russia-final](data/russia-final/). Неоднозначные сведения
первичного импорта уточнялись по дополнительным источникам. Например, для Волги
выбран обычный географический ответ «Каспийское море», а местоположение
Румянцевского музея привязано к 1900 году. История данных сохранена для воспроизведения.

## Оценка

Один факт присутствует в обучении с несколькими вопросами. Для проверки
удерживается другая формулировка, отсутствующая в train всех этапов.
Следовательно, проверяются вопросы об известных фактах, а не новые фактические знания.
Это внутренние, созданные для проекта наборы; метрики не заменяют внешний бенчмарк.

| Набор и реализация | Совпадений с эталоном |
|---|---:|
| Знакомые вопросы, FP32 Python | 1000/1000 |
| Знакомые вопросы, int8 Python / нативный C | 1000/1000 |
| Все новые формулировки, int8 Python | 863/1000 |
| Выборка новых формулировок, нативный C / Windows EXE | 180/200 |
| Настоящий DOS EXE в DOSBox-X | 13/14 |
| Зафиксированные регрессионные примеры, int8 Python | 8/8 |

Метрика — точное совпадение с одним из коротких эталонов после регистра и
конечной пунктуации. Данные и ответы доступны в [reports/russia](reports/russia/)
и [reports/windows](reports/windows/).

Расширение модели сопровождалось ухудшением на старых удержанных вопросах:

| Старый контроль, int8 Python | r2 | r3 |
|---|---:|---:|
| Знакомые вопросы | 40/40 | 40/40 |
| Перефразировки | 16/40 | 7/40 |
| Арифметика, новые формулировки | 19/30 | 11/30 |
| Неизвестные вопросы | 13/15 | 9/15 |

## Ограничения

* Модель может выдавать вымышленные имена, неправильные числа и другие ложные ответы.
* Чувствительность к формулировке, пунктуации и длине вопроса остаётся высокой.
* Ответ на неизвестный вопрос не всегда выражает отсутствие знаний.
* Арифметика изучалась на ограниченном наборе примеров; она не гарантируется для произвольных выражений.
* Общая длина вопроса и ответа ограничена контекстом 128; ввод — 72 символами.
* Информация о должностях, организациях и других изменяемых объектах устаревает.
* Переход на Windows меняет платформу выполнения и ввод/вывод, сохраняя знания модели.
* Поставляемый DOS EXE проверялся в эмуляторе; реальное оборудование и сборка Turbo C не проверялись.

Показательная ошибка: «кто занимает пост президента рф?» дало «михаяль?»
в DOSBox-X. Обычный вопрос «кто президент россии?» дал «владимир путин.».
Поэтому для утверждения фактов следует обращаться к указанным первоисточникам.

Tiny-RU 2.1r3 для Windows 10/11 x64

Запуск из CMD: TINYWIN.EXE
Можно также открыть TINYWIN.EXE или START.CMD двойным щелчком.
TINY.BIN должен лежать рядом с TINYWIN.EXE. Рабочая папка CMD может быть любой.
DOSBox, Python, установка библиотек и доступ к интернету не требуются.

Русская раскладка переключается обычными средствами Windows: Win+Space
или настроенным у вас сочетанием клавиш. Команда chcp не требуется.
Для выхода введите QUIT или EXIT латинскими буквами и нажмите Enter.

Примеры вопросов:
  кто президент россии?
  какая столица россии?
  куда впадает река волга?
  в каком году основан город санкт-петербург?
  сколько будет 2+2

Вопрос — до 72 символов. Программа отвечает той же маленькой нейросетью,
что и DOS-версия. Переход на Windows не исправляет ошибки знаний модели.
Сведения о России соответствуют срезу источников на 24 ноября 2026 года;
модель не обновляет их автоматически.

По умолчанию используется детерминированная генерация. Например, TINYWIN.EXE 3
включает случайное семплирование; для проверяемых фактов лучше обычный запуск.

Перенаправление: TINYWIN.EXE < questions.txt > answers.txt
Файл вопросов рекомендуется сохранять в UTF-8; BOM допускается.
Ответы при перенаправлении всегда записываются в UTF-8.
Для старых файлов есть флаги /CP866 и /CP1251, для строгого UTF-8 — /UTF8.
Эти флаги относятся только к файлам и каналам; консоль использует Unicode.

Веса TINY.BIN побайтно совпадают с DOS-сборкой r3. Ответ вычисляется локально,
без таблицы готовых ответов. Код и формулировки — MIT, см. LICENSE.TXT.
Сведения о runtime компилятора приведены в THIRD_PARTY.txt.

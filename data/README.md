# Данные Tiny-RU

## Текущий набор

Для описания знаний поставляемой модели и оценки используйте `russia-final/`:

| Файл | Содержание |
|---|---|
| `facts.txt` | Читаемый список 1000 фактических записей со ссылками |
| `facts.jsonl` | Те же факты, свойства, источники и сведения об уточнениях |
| `train.jsonl` | 37 581 обучающая строка: варианты вопросов и повторение старых тем |
| `test.jsonl` | 1000 удержанных формулировок известных фактов |
| `control.jsonl` | 1000 знакомых вопросов и выборка 200 удержанных |
| `smoke.jsonl` | 14 вопросов небольшого DOS-прогона |
| `validation.jsonl` | Валидационные вопросы текущего и предыдущего этапов |
| `manifest.json` | Количества, SHA-256 и перечень исправленных записей |

Число фактов — число связей «объект — свойство». Варианты вопросов,
альтернативные допустимые ответы и тренировочные повторения не считаются
новыми фактами. Метрика на удержанных вопросах оценивает другие формулировки
обученных сведений, а не новые знания.

## Зачем сохранены предыдущие наборы

| Каталог | Роль в обучении |
|---|---|
| Корень `data/` | Русский исходный этап v2: 1185 записей, большая часть — арифметика |
| `improved/` | Дообучение r2 и регрессионные примеры |
| `russia/` | Первый импорт 1000 записей и краткие вопросы |
| `russia-expanded/` | Дополнительные формулировки с удержанием варианта на факт |
| `russia-calibration/` | Короткие естественные вопросы |
| `russia-final/` | Итоговые эталоны после уточнения неоднозначных источников |

Это история конкретного обучения. Ранние наборы содержат впоследствии
исправленные значения; применять их как актуальный справочник не следует.
Например, первичный импорт включал Каму среди ответов об устье Волги.
В финальном наборе сохранён обычный географический ответ «Каспийское море».

Снимки структурированных источников и запросов находятся в `russia/sources/`.
Они позволяют повторить генерацию без скачивания новых данных. Живой Wikidata
может измениться, поэтому повторное скачивание создаёт новый срез.
Скрипты получения данных: `scripts/fetch_russia_sources.py` и
`scripts/fetch_russia_genders.py`.

Дата среза — 24 ноября 2026 года. Полный независимый аудит всех связей не
выполнялся. Условия использования и происхождение — [DATA_LICENSES.md](../DATA_LICENSES.md).

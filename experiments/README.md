# Исходные чекпоинты

В репозиторий включены два начальных русских чекпоинта, необходимые для
воспроизведения выполненных этапов:

* `v2-release/baseline.pt` — результат русского обучения со случайных весов,
  6000 шагов. Из него начиналось дообучение r2.
* `r2-release/baseline.pt` — результат ещё 2000 + 1000 шагов. Из него начиналось
  обучение r3 на данных о России.

`r2-release/TINY.BIN` — квантованный вариант r2 для сравнения и отдельного
эксперимента; его словарь совпадает со словарём r3. `int8.json` и `environment.json`
в этой папке описывают старую версию, а не текущий выпуск.

В v2-чекпоинте абсолютные пути из метаданных заменены относительными. Тензоры,
optimizer и RNG оставлены без изменений и проверены на точное совпадение.
Соответствующая отметка и SHA-256 находятся в [PUBLICATION.json](../PUBLICATION.json).
Это изменение сериализованных метаданных меняет хеш `.pt`, сохраняя модель.

Текущий финальный чекпоинт — `training/release.pt`; подробные команды —
[docs/TRAINING.md](../docs/TRAINING.md). Английские веса исходного проекта
в этих файлах не используются.
